## 🚀 Start in seconds

<details open>
<summary><strong>Cloud (fastest)</strong></summary>

<br />

```bash
# 1) Create a project → https://wowsql.com
# 2) Install the SDK
npm install @wowsql/sdk
```

```ts
import { createClient } from '@wowsql/sdk'

const wow = createClient(WOWSQL_URL, WOWSQL_KEY)

const { data } = await wow.from('users').select('*')
```

</details>

<details>
<summary><strong>Self-hosted (Docker)</strong></summary>

<br />

```bash
git clone https://github.com/WoWSQL/WoWSQL.git
cd WoWSQL/docker
cp .env.example .env
docker compose pull && docker compose up -d
```

- Dashboard → `http://localhost:3000`
- API → `http://localhost:8080`

</details>
